Guia rápido para a turma

O propósito é entender qualidade em um sistema de gestão de engenharia sem depender de APIs privadas ou infraestrutura paga.

1
Instale Node.js 22.16+ ou versão LTS compatível. Abra a pasta no VS Code.
2
No terminal execute npm start e abra http://127.0.0.1:8787.
3
Cadastre clientes fictícios, crie pré-notas e execute testes na aba Testes de carga.
4
Rode npm test (testes de unidade, integração e comportamentais) e npm run load (carga por HTTP).
5
Leia docs/GUIA_AULA_6.md, docs/QUALIDADE_E_CRITERIOS.md e os roteiros de JMeter/k6.
6
Não coloque credenciais, dados verdadeiros ou links de produção nos testes.
SQLite cria automaticamente .data/ld_laboratorio.sqlite. Esse arquivo fica fora do Git graças ao .gitignore. A interface demonstra o laboratório, não a autenticação nem a emissão fiscal de um ERP real.
