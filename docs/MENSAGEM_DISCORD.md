Pessoal, montei um laboratório prático usando um cenário da minha empresa de engenharia pra aplicar as aulas de **Qualidade de Software** da Pós-Tech. 😄

Dá pra cadastrar clientes fictícios, gerar centenas ou milhares de pré-notas (sem valor fiscal) e fazer testes de unidade, integração, BDD e carga HTTP. Tem painel web, banco SQLite que salva os dados e resultados p95/p99.

Tudo roda no VS Code com `npm start`, sem login, Docker ou Supabase. Pra testar: `npm test` e `npm run load`.

Vou compartilhar o GitHub com o código e um roteiro pra quem quiser rodar e modificar junto. É só um simulador educacional, não emite nota fiscal de verdade. 🚀
